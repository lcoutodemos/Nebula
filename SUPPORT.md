# Support

Nebula is maintained in spare time. Use GitHub Issues for bugs and feature requests; search the existing
issues first.

For a bug, describe what you did, what you expected and what happened, and include your Windows version,
PC architecture (x64 or Arm64) and GPU. The app log, `application.log`, often explains a failure.
[docs/architecture.md](docs/architecture.md#local-data) says where to find it. It contains file paths from
your PC, so review it before you attach it.

For security issues, see [SECURITY.md](SECURITY.md).
